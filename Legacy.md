# Legacy materials

This project was developed from a TensorFlow Object Detection learning workflow and intentionally preserves parts of that original setup.

## Preserved course-derived materials

- Original notebook structure for image collection and TensorFlow Object Detection setup
- Earlier generic README and error guide
- TensorFlow Models source setup and TFRecord helper script

## Project-specific adaptations

- A single `licence` detection class
- Vehicle-image dataset, Pascal VOC XML annotations, and TFRecord files
- SSD MobileNet V2 FPNLite configuration and trained checkpoints
- EasyOCR-based licence-plate text recognition
- Real-time webcam detection, cropped-region saving, and CSV experiment logs

## Reference

The original learning workflow was based on [Nicholas Renotte's TFODCourse](https://github.com/nicknochnack/TFODCourse). This attribution documents provenance; the ANPR adaptations and recorded experiments are retained as this project's own coursework implementation.
